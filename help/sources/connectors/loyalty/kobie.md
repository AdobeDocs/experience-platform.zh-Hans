# [!DNL Kobie]

[!DNL Kobie Alchemy Loyalty Cloud (KALC)]是一个高度可配置、安全且可扩展的MACH平台，可适应您的忠诚度策略 — 加快实现价值的时间，提高效率，并通过企业级治理保护您的品牌。 通过跨CDP、CRM、CMS等产品的无缝集成，[!DNL KALC]使营销人员能够在每个渠道中提供实时个性化，同时提供灵活性和可跟踪性，以随着品牌忠诚度的增长而不断发展。

>[!NOTE]
>
>**在Experience Platform上配置权限**
>
>您必须同时为您的帐户启用&#x200B;**[!UICONTROL View Sources]**&#x200B;和&#x200B;**[!UICONTROL Manage Sources]**&#x200B;权限，才能将您的[!DNL Kobie Streaming Events]帐户连接到Experience Platform。 请联系您的产品管理员以获取必要的权限。 有关详细信息，请阅读[访问控制UI指南](../../../access-control/abac/ui/permissions.md)。

使用源目录中的[[!DNL Kobie Streaming Events] 源](../../tutorials/ui/create/loyalty/kobie-streaming.md)将您的[!DNL Kobie]帐户中的忠诚度数据流式传输到Adobe Experience Platform。
